## Project

### [European Road Carrier Due-Diligence & Cost Monitor](https://github.com/simuno/carrier-due-diligence-powerbi)

Power BI report on 24 European road carriers, built from public sources only: what a buyer can verify before a
tender, financial red flags, fleet and registrations, and a rate-increase check that weights a real carrier's cost
structure by diesel, toll, wage and contract-rate indices.
